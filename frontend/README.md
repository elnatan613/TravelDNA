# TravelDNA React

ממשק React בעברית (RTL), עם API בפייתון שמשתמש במנגנון ההתאמה ובסוכן ה־RAG הקיימים.

השאלון החדש משתמש בהרכב הנוסעים, 12 חוויות עם תמונות והחלקה, והערות בסיום. פרטי ההתנהגות, המיפוי והמגבלות מופיעים ב־[SURVEY.md](SURVEY.md).

## הרצה

מהתיקייה הראשית, התקינו את `requirements.txt` באמצעות סביבת Python של הפרויקט. מפתח `GEMINI_API_KEY` נשאר בקובץ `.env` בשרת בלבד.

```sh
python -m pip install -r requirements.txt
cd frontend
npm ci
npm run build
cd ..
python -m uvicorn app.api:app --host 127.0.0.1 --port 8000
```

פתחו http://127.0.0.1:8000. ב־Windows אפשר להריץ `run_web.bat` אחרי הבנייה. לפיתוח: הפעילו את ה־API ובטרמינל נוסף `npm run dev` מתוך `frontend`; Vite מעביר בקשות `/api` לשרת המקומי.

## היכולות

- התאמת יעד עם שבעת צירי ההעדפות, חשיבות, טקסט חופשי וסינון כשרות, או בחירת יעד ישירה.
- תאריכים, תקציב וקצב; מסלול יומי עם מתג להצגת שעות משוערות.
- ייצוא UTF-8 לקובץ טקסט ו־JSON, כולל בדיקות ואריזה.
- בדיקות דטרמיניסטיות לעומס, זמנים לא תקינים וחפיפות. סף העומס תלוי בקצב שנבחר.
- קריאת מודל נפרדת לביקורת בסגנון מדריך טיולים, עם ציון והערות שמסומנים כהערכת מודל.
- רשימת אריזה לפי תחזית [Open-Meteo](https://open-meteo.com/en/docs) לכל תאריכי הטיול, עד 16 ימים קדימה כולל היום. מחוץ לטווח, בכשל רשת או בנתונים חלקיים מוצגת רשימה בסיסית ללא המצאת תחזית.

## גבולות האימות

המאגר הקיים אינו כולל מקור חי לזמני נסיעה או שעות פתיחה לפי תאריך. לכן במסלולים שנוצרים כרגע, בדיקות אלה מסומנות כחסרות והסטטוס לכל היותר חלקי. ציון המדריך אינו ציון אימות. מנוע הבדיקות תומך בנתוני נסיעה ממקור חיצוני, במרחק אווירי ממיקומים מתועדים ובשעות פתיחה עם מקור ותאריך, אך עדיין נדרש לחבר ספק נתונים כדי להפעיל אותן על מסלולים אמיתיים. המודל אינו רשאי לייצר בעצמו שדות ראיות אלה.

הבדיקה הגיאוגרפית היא מסנן אי־סבירות שמרני, לא מנוע ניווט. שעות הפעילויות הן הצעה בזמן מקומי, ללא פעילות שחוצה חצות. לא תומכים עדיין בפיצולי שעות פתיחה או בשעות סגירה אחרי חצות.

השרת מיועד לשימוש מקומי, ללא אימות משתמשים או אחסון מסלולים. בכל רגע נבנה מסלול אחד לתהליך כדי להגן מפני בקשות מקבילות יקרות. תהליך בניית המסלול כולל את סוכן ה־RAG, המרה למבנה וביקורת; לכן הוא ארוך יותר מבניית הטקסט הקודמת. כשל בביקורת בלבד אינו מוחק את המסלול.
