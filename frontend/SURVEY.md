# שאלון החוויות של TravelDNA

## הזרימה

הרכב הנוסעים → 12 כרטיסי חוויות → הערות אופציונליות → שלוש המלצות או בחירת יעד ישירה → מסלול.

הכרטיסים מתייחסים לטיול הנוכחי בלבד. אין מסך אישור פרופיל ואין דירוגי חשיבות. ימינה היא ״כן, מתאים״ ושמאלה ״לא הפעם״ גם בממשק RTL. כפתורי פעולה ומקשי החצים מאפשרים אותה התנהגות במחשב; רווח מדלג כאשר הכרטיס ממוקד. החלקה אנכית לא רושמת בחירה. ניתן לחזור לכרטיס קודם ולשנות אותו.

בחירת משפחה חושפת שאלת ילדים וגילים אופציונלית. שינוי להרכב אחר מנקה את נתוני הילדים. טיוטת השאלון נשמרת ב־sessionStorage באותה לשונית, כולל דילוגים והערות. היא אינה פרופיל קבוע. ״טיול חדש״ מאפס את השאלון ואת פרטי התכנון. כשל בכתיבה לאחסון אינו מונע שימוש.

## חיבור להתאמה ולתכנון

`data/experience_cards.json` הוא מקור משותף ל־React ולשרת: מזהה, משפט, תיאור תמונה ומיפוי מוגבל לשבעת צירי הדירוג הקיימים.

- דילוג לא מוסיף ראיות או משקל. דחייה של חוויה ספציפית חלשה מבחירה חיובית ואינה שלילת תחום שלם.
- אין הסקת תקציב או נגישות מתמונה או מהרכב הנוסעים.
- מאחר שבנתוני היעדים הקיימים אין צירים נפרדים לחוף, הליכה ארוכה וקניות, הבחירות הללו נשמרות במלואן למתכנן המסלול ואינן מומצאות כציוני יעד חדשים. יש להרחיב את נתוני היעדים לפני דירוג מדויק של היבטים אלה.
- שילובים כגון עיר וטבע נשמרים במפורש בתיאור למתכנן. בחירת ימים מלאים וגם זמן חופשי מתורגמת לגיוון בין ימים/חלקי יום.
- `/api/discover` משתמש במיפוי הדטרמיניסטי. רק אם יש הערות מופעלת קריאת מודל קצרה לחילוץ העדפות מפורשות ודרישת כשרות. ההערות גוברות על ההסקה מהכרטיסים. כשל בשירות מחזיר הודעה ומאפשר ניסיון חוזר בלי לאבד את הטיוטה.
- ללא ראיות לצירים הקיימים מוצגות אפשרויות ללא אחוז התאמה. אחוזי ההתאמה הם מדד מרחק לפי הנתונים הקיימים, לא הסתברות להנאה.
- `/api/plan` מקבל את השאלון המלא ומרכיב את תיאור הטיול בצד השרת. ההערות, הרכב הנוסעים, הגילים, החוויות שאושרו והחוויות שנדחו מגיעים למתכנן.

הבדיקות הדטרמיניסטיות והגבלות המקורות החיים של בדיקת ההיתכנות נשארות כפי שמתואר ב־README.

## תמונות

12 תמונות מקוריות נוצרו באמצעות כלי image_gen המובנה ונשמרו ב־`frontend/public/experiences/` כקובצי WebP נפרדים, ללא טקסט; הכותרות מוצגות ב־React. הם מדגימים חוויות ולא מהווים תיעוד של מקומות מסוימים. סצנות ותיאור סגנון היצירה מופיעים ב־`manifest.json` באותה תיקייה.

הממשק טוען מראש את התמונה הבאה בלבד. התמונות הותאמו ל־900×1200 ונשמרו כ־WebP; משקל כל ספריית הכרטיסים הוא כ־2MB.

## אימות

בדיקות מצב השאלון: השלמה, דילוג, חזרה והחלפת תשובה, מניעת אירוע גרירה ישן, שחזור רענון, ניקוי פרטי ילדים וקיום התמונות.

בדיקות שרת: היעדר ראיות, שילוב עיר וטבע, משקל דחייה, קצב מעורב, גילים, קדימות הערות, סינון כשרות, כשל ספק והעברת השאלון למתכנן.

```sh
python -m pytest tests/test_survey.py tests/test_web_features.py
cd frontend
npm test
npm run build
```
