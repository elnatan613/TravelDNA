# TravelDNA

מערכת שמאפיינת את "טיפוס המטייל" ומתאימה לו יעד טיול (מדינה/אזור/עיר) - פרויקט גמר בקורס AI Engineering.

## איך לעבוד עם זה בשניים במקביל

הפרויקט מחולק לשני חלקים עצמאיים שנפגשים רק דרך `config.py` ודרך פורמט
קובץ ה-JSON של היעדים. ככה כל אחד יכול לעבוד בלי לחכות לשני, ובלי
לגרום ל-merge conflicts על אותם קבצים.

**חלק א' - `nlp/`** (פרופיל מטייל)
קלט: תשובות טקסט חופשיות מהמשתמש
פלט: וקטור ציונים 0-1 על הצירים שמוגדרים ב-`config.py`
מי שעובד כאן לא צריך לגעת בשום קובץ אחר.

**חלק ב' - `scripts/` + `matching/`** (דאטה על יעדים + התאמה)
`scripts/` - שליפת דאטה גולמי ותרגומו לציונים לכל עיר (GeoNames, OpenTripMap, Numbeo, כשרות)
`matching/` - חישוב מרחק משוקלל בין וקטור מטייל לוקטור יעד
מי שעובד כאן לא צריך לגעת בתיקיית `nlp/`.

**החוזה המשותף - `config.py`**
כל שינוי בשמות הצירים (`AXES`) חייב תיאום בין שני הצדדים לפני שמבצעים אותו,
כי זה משפיע על שניהם. חוץ מזה, כל אחד עובד בתיקייה שלו בלי תלות.

## מבנה התיקיות

```
travel-dna/
├── config.py              # הגדרת הצירים והמשקלים - "החוזה" המשותף
├── data/
│   ├── raw/                # דאטה גולמי לפני עיבוד
│   └── processed/          # destinations.json - הפלט הסופי לשימוש matching
├── scripts/
│   ├── destination_scraper.py   # GeoNames + OpenTripMap
│   ├── numbeo_fetcher.py        # ציר תקציב-יוקרה (TODO)
│   └── kashrut_fetcher.py       # ציר קהילתי-יהודי (TODO)
├── nlp/
│   └── profile_extractor.py     # חילוץ פרופיל מטייל מטקסט (TODO - כרגע דמה)
├── matching/
│   └── matcher.py                # מרחק משוקלל + דירוג יעדים (עובד עם דאטה דמה)
├── app/
│   └── demo.py                   # דמו Streamlit שמחבר הכל
└── tests/
```

## התקנה

```bash
pip install -r requirements.txt
```

יש להירשם (חינם) ולקבל מפתחות:
- GeoNames: https://www.geonames.org/login
- OpenTripMap: https://opentripmap.io/product

ולעדכן אותם בראש `scripts/destination_scraper.py`.

## הרצה מהירה (עם דאטה דמה, בלי לחכות לשום API)

```bash
python matching/matcher.py       # בודק את מנוע ההתאמה על נתוני דוגמה
python nlp/profile_extractor.py  # בודק את חילוץ הפרופיל (גרסת דמה)
streamlit run app/demo.py        # דמו מלא, עם התראה אם דאטה חסר
```
